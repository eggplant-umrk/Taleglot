# ナレーション原稿（VOICEVOX用）

`scripts/generate-narration.mjs` が読み込む台本。1エントリ = 1シーン分の音声ファイル。
デスクトップでVOICEVOX ENGINEを起動してから `npm run narration` を実行すると、
`public/audio/narration/sceneXX.wav` が生成されます。

読み仮名の誤読が起きやすい語は `[表記|読み]` の形でメモしてあるので、
生成後に実際の音声を聞いて発音を確認し、必要ならスクリプト側の読みを調整してください。

## scene01（オープニング, 4秒）

```
物語を読みながら、タイ語と文化に出会う。
```

## scene02（読む, 12秒）

```
絵本をひらいて、物語のページをめくっていく。
```

## scene03（発見する, 16秒）

```
本文の中の言葉をタップすると、その言葉に込められた文化が見えてくる。
[絵|え]の中の黄金のハゼにも、同じように[触|さわ]れる場所が隠れている。
```

読み仮名メモ:
- 絵 → え（「絵本」の「え」と同じ）
- 触れる → さわれる

## scene04（コレクションする, 9秒）

```
見つけた言葉は、コレクションにひとつずつ集まっていく。
```

## scene05（振り返る, 9秒）

```
フラッシュカードをめくって、覚えた言葉を振り返る。
```

## scene06（クロージング, 4秒）

```
物語から、タイ語と文化を学ぼう。[Taleglot|テルグロット]。
```

読み仮名メモ:
- Taleglot → テルグロット
