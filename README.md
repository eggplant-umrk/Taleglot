# Taleglot（タイ語えほん）

**Taleglot**は、タイの民話を絵本形式で読みながらタイ語を学べる学習アプリの雛形です。React + Vite で構築しています。

対象は小学校高学年くらいの子供、タイ語は初学者向け（文字は少しずつ、ローマ字/カタカナの発音表記を併記）を想定しています。

## セットアップ

```bash
npm install
npm run dev
```

## 構成

```
src/
  stories/
    story01.json      物語データ（「黄金のハゼ」実データ。差し替え/追加方法は下記参照）
  components/
    StoryViewer.jsx    絵本ビューア（実装済み）
    Review.jsx          振り返り（フラッシュカード、実装済み）
    Collection.jsx       単語コレクション画面（実装済み）
  hooks/
    useCollectedWords.js  収集済み単語のlocalStorage永続化
  App.jsx               物語データの読み込み・StoryViewer⇄Review⇄Collectionの画面切り替え
public/
  stories/story01/       物語ごとの画像・音声ファイルの配置先（現在は空）
```

StoryViewer.jsx / Review.jsx / Collection.jsx は実装済みです。App.jsx（複数話対応時の読み込み方法）など、一部のファイルには今後の実装課題がファイル冒頭の `TODO:` コメントとして残っています。

## 物語データの追加方法

### 1. JSON ファイルを作成する

`src/stories/storyXX.json` として、以下の形式でファイルを作成します（`story01.json` はダミーデータなので、内容を実データに差し替えるか、新しい番号でコピーして使ってください）。

> **注記:** `story01.json` の中身は現時点でまだ新スキーマ（`audioJa`/`audioThai`・`annotations`・`review[].id`など）に対応済みではありません。コピーして使う場合は、下記の最新スキーマに沿って書き直してください。

```json
{
  "id": "story01",
  "title": "物語のタイトル",
  "titleThai": "タイ語のタイトル（任意）",
  "source": "出典（実在するタイの民話名など）",
  "pages": [
    {
      "id": 1,
      "text": [
        "むかしむかし、村はずれに{{gongsai:ご先祖さま}}を祭るお堂がありました。",
        "村の人たちは、毎日そこでお祈りをしていました。"
      ],
      "thai": [
        "กาลครั้งหนึ่ง ที่ชายหมู่บ้านมี{{gongsai:ศาลบรรพบุรุษ}}อยู่หลังหนึ่ง",
        "ชาวบ้านมักจะมาสวดมนต์ที่นี่ทุกวัน"
      ],
      "thaiReading": ["ローマ字/カタカナ表記の読み方（任意）", "同上"],
      "images": ["/stories/story01/page01.png", "/stories/story01/page02.png"],
      "audioJa": "/stories/story01/page01_ja.mp3",
      "audioThai": "/stories/story01/page01_th.mp3"
    }
  ],
  "annotations": [
    {
      "id": "gongsai",
      "word": "ご先祖さま",
      "categories": {
        "lifestyle": "タイの家庭には祖先を祀るお堂があり、日々お供えをする習慣がある。",
        "values": "祖先を敬う気持ちは、タイの人々にとって大切な価値観のひとつ。"
      }
    }
  ],
  "review": [
    {
      "id": "review01",
      "annotationId": "gongsai",
      "image": "/stories/story01/review01.png",
      "word": "บรรพบุรุษ",
      "reading": "ローマ字/カタカナ表記の読み方（任意）",
      "meaning": "ご先祖さま",
      "audio": "/stories/story01/review01.mp3"
    }
  ]
}
```

#### `text` / `thai`（コマ単位の配列）について

- `pages[].text` / `pages[].thai` は、1画面に表示する「コマ」ごとに区切った**文字列の配列**です。配列の1要素が1コマに対応し、「次へ」を押すたびに次の要素へ切り替わります（前のコマは消え、新しいコマだけが表示される入れ替わり式）。そのページの最後のコマまで表示し終えてから、次に「次へ」を押すと初めて次のページ（新しい画像）に進みます。
- 1コマの目安は2〜3文程度（画面に無理なく収まる分量）です。
- `text` と `thai` は**同じ要素数**にしてください。同じ添字（インデックス）のコマが対応する内容になります（例: `text[2]` と `thai[2]` が同じコマ）。`thai` を省略する場合は `thai` キーごと省略します（1ページの途中だけタイ語が無い、という状態は想定していません）。
- `thaiReading`（任意項目）も使う場合は同様に配列にし、`text`/`thai` と同じ要素数にしてください。
- 1話あたりのページ数の目安（3〜5ページ）とは別に、1ページあたりのコマ数に決まった上限はありません。本文の分量に応じて自然に区切ってください。

#### `images`（コマ単位の画像）について

- `pages[].images` は `text`/`thai` と**同じ要素数**の配列で、コマごとに表示する画像（イラスト）を切り替えられます。同じ画像を複数コマで使い回したい場合は、同じパスを繰り返し指定してください。
- 1ページ内で画像を切り替える必要がない場合（イラストがページ単位でしか用意できない場合など）は、`images` の代わりに従来通り単数形の `image` を指定できます（そのページの全コマで同じ画像が表示されます）。`images` が指定されている場合はそちらが優先されます。

#### 本文中の単語タップ（太字）について

- コマの文字列（`text[]` / `thai[]` の各要素）の中で `{{id:表示テキスト}}` という記法を使うと、`表示テキスト` の部分が本文中で太字・タップ可能になります。`id` は `annotations[].id` と対応させてください。
- 本文中の重要な単語だけにこのマーカーを付けてください（全部の単語を太字にする必要はありません）。
- `text`（日本語）と `thai`（タイ語）で別々にマーカーを付けられます。日本語だけ・タイ語だけに付ける、両方に付けて同じ `id` を指す、なども可能です。
- マーカーが付いていない本文には何もマークアップを書かなくてよく、通常のプレーンテキストのままで構いません。
- マーカーがどのコマに属するかは、そのマーカーを含むコマの文字列にそのまま書くだけで問題ありません（コマをまたいだマーカーは書けません）。

#### `annotations`（単語の詳細カード）について

- 太字をタップしたときに開く詳細カードのデータです。カードの中身は「暮らし」「ことば」「価値観」の3カテゴリ（`categories.lifestyle` / `categories.language` / `categories.values`）で固定です。
- 該当する情報がないカテゴリはキーごと省略して構いません（上の例では `language` を省略しています）。空欄をUI側でどう扱うか（非表示にする／「情報なし」と表示する）は実装時に決めます。
- `annotations[].id` は物語内で一意にしてください。将来のコレクション機能（フェーズ2で予定。下記「単語コレクション機能の下地について」参照）で、タップした単語を記録するためのキーとして使う想定です。
- カードの閉じ方は、×ボタン・カード外タップの両方に対応しています（実装済み）。

#### `review`（振り返りフラッシュカード）について

- 振り返り画面はクイズ形式ではなく、フラッシュカード形式です。表面が `image`（絵）、裏面が `word`・`reading`・`meaning`（単語・読み方・意味）です。
- `annotationId` は対応する本文中の単語の `annotations[].id` です（任意項目。無くてもよい）。
- 絵本を最後まで読み終えたら、ボタン操作なしで自動的にこの振り返り画面へ遷移する想定です。

#### `audioJa` / `audioThai`（音声）について

- `audioJa` / `audioThai` は`text`/`thai`とは異なり、コマ単位ではなく**ページ単位のまま**です（1ページに1つの音声ファイル）。コマを送っても同じ音声の続きとして再生され、再生中にコマを送っても音声が途切れることはありません。
- 表示中のコマの文章だけを読み上げるようなコマ単位の音声には対応していません。ページ全体の読み上げ、という位置づけです。

#### 任意項目まとめ

- `thai` / `thaiReading` / `titleThai` / `image` / `images` / `audioJa` / `audioThai` / `annotations` / `annotations[].categories.*`（各カテゴリ） / `review[].reading` / `review[].annotationId` は任意項目です。無い場合はその部分の表示・機能が省略されます。
- `thai` が無いページでは、そのページのタイ語表示トグル自体を表示しません（ONにしても表示するものが無いため）。
- 1話あたり3〜5ページ程度を目安にしてください。
- `review` はその物語の振り返り（フラッシュカード）に使う単語リストです。

### 2. 画像・音声ファイルを配置する

`public/stories/storyXX/` フォルダの下に、JSON内の `image` / `images` / `audioJa` / `audioThai` / `review[].image` / `review[].audio` に指定したパスと同じファイル名で配置してください。

```
public/stories/story01/
  page01.png
  page01_ja.mp3
  page01_th.mp3
  page02.png
  page02_ja.mp3
  page02_th.mp3
  ...
  review01.png
  review01.mp3
  ...
```

- イラスト担当者が後から画像・音声ファイルを追加する運用を想定しています。ファイル未配置時は画像がプレースホルダー表示になり、音声ファイルが無いページ・カードでは再生ボタン自体が表示されません（`StoryViewer.jsx` / `Review.jsx` で実装済み）。
- 音声は日本語・タイ語で別ファイルです（`_ja` / `_th`）。日本語・タイ語はそれぞれ独立して表示オン/オフ・再生/停止ができる想定なので、どちらか一方しか用意できていない場合でも構いません。

### 3. アプリに読み込ませる

`src/App.jsx` は現状 `story01.json` を直接 import し、StoryViewerを最後まで読み終えると自動的にReview（振り返り）へ画面遷移する実装になっています。複数話に対応する場合の読み込み方法（一覧画面など）は今後の実装課題です。当面は物語一覧画面を作らず、1話固定で表示する方針です（`App.jsx` 冒頭の TODO コメント参照）。

### 4. 単語コレクション機能について

- 本文中の単語タップ、およびReviewのフラッシュカードをめくった単語は、`useCollectedWords`フック（`src/hooks/useCollectedWords.js`）経由でブラウザの`localStorage`（キー: `taleglot:collectedWords`）に自動的に記録されます。`annotations[].id`が物語内で一意であることを前提に、`{ storyId, wordId }`の組み合わせで保存されます。
- 実際に保存される形式は以下の通りです（`localStorage.getItem('taleglot:collectedWords')`の中身）。

```json
[
  { "storyId": "story01", "wordId": "gongsai" }
]
```

- コレクション画面（`src/components/Collection.jsx`）で、収集済みの単語を一覧表示します。App.jsxの「📚コレクション」ボタンから、StoryViewer/Reviewどちらの画面からでも遷移できます。
- コレクション画面のカードは、対応する`review[]`エントリ（`annotationId`が一致するもの）があれば画像・タイ語・意味を表示し、無ければ意味（`annotations[].word`）のみを表示します。
